# 🤖 AI Chatbot with LangChain, Groq & Streamlit

A modern AI chatbot built with **Python, LangChain, Groq LLMs, and Streamlit**. This project demonstrates how to build an interactive conversational AI application using an LLM API and LangChain's prompt and chain architecture.

The chatbot provides a simple and user-friendly interface where users can enter questions and receive intelligent AI-generated responses in real time.

## 🚀 Project Overview

This project was created as a practical implementation of an **LLM-powered chatbot**. It demonstrates how modern AI applications connect a frontend interface with a Large Language Model through an API and use **LangChain** to organize prompts, models, and application logic.

The application uses **Streamlit** to provide the web interface, **LangChain** to manage the LLM workflow, and **Groq** to provide fast inference from supported large language models.

The main goal of this project is to understand the fundamentals of:

* Large Language Models (LLMs)
* Prompt Engineering
* LangChain
* LLM API integration
* Environment variables and API security
* Streamlit application development
* AI chatbot architecture
* Chain-based LLM workflows

## ✨ Features

### 💬 Interactive AI Chatbot

Users can enter questions or messages through the Streamlit interface and receive responses generated by the selected LLM.

### 🧠 Large Language Model Integration

The chatbot connects to an LLM through the Groq API, allowing the application to generate natural-language responses.

### 🔗 LangChain Integration

LangChain is used to organize the chatbot workflow. The application demonstrates how prompts and LLMs can be connected together using LangChain's runnable and chain architecture.

### 🎯 Prompt Engineering

The project includes structured prompts that define how the AI should behave and respond to users.

This demonstrates important prompt-engineering concepts such as:

* Giving the model a specific role
* Providing clear instructions
* Controlling response behavior
* Providing user context
* Defining expected output
* Reducing irrelevant responses

### ⚡ Fast LLM Inference

The application uses Groq's inference infrastructure to provide fast responses from supported language models.

### 🌐 Streamlit Interface

Streamlit provides a lightweight web interface without requiring a separate frontend framework.

### 🔐 Environment Variable Security

API credentials are stored using environment variables rather than hard-coded directly into the application.

The `.env` file is excluded from Git using `.gitignore`.

## ⚙️ How It Works

When a user enters a question in the Streamlit application, the input is passed to the LangChain workflow.

The workflow combines the user's question with the configured prompt and sends the resulting request to the Groq-powered language model.

The model processes the request and generates a response.

The response is then returned to the Streamlit interface and displayed to the user.

In simplified form:

```text
User Question
      ↓
Streamlit
      ↓
LangChain Prompt
      ↓
LLM
      ↓
Groq API
      ↓
Generated Response
      ↓
Streamlit UI
```

## 🧠 Prompt Engineering

One of the main learning objectives of this project is understanding **prompt engineering**.

Instead of sending only the user's question to the model, the application can provide additional instructions that control the model's behavior.

For example:

```text
You are a helpful AI assistant.

Answer the user's question clearly and accurately.

Rules:
- Be helpful.
- Use simple language.
- Stay relevant to the question.
- Do not invent information.
```

This gives the model additional context and helps produce more consistent responses.

## 🔐 API Key Configuration

The application requires a Groq API key.

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Never publish your real API key on GitHub.

The `.gitignore` file should contain:

```text
.env
venv/
__pycache__/
*.pyc
```

The `.env.example` file can be safely committed because it should contain only a placeholder:

```env
GROQ_API_KEY=your_groq_api_key_here
```

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/saqib0-cpu/chatbot-streamlit.git
```

Move into the project directory:

```bash
cd chatbot-streamlit
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Create your `.env` file:

```env
GROQ_API_KEY=your_groq_api_key_here
```

---

## ▶️ Running the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

Streamlit will provide a local URL where you can open the chatbot in your browser.

Usually, the application will be available at:

```text
http://localhost:8501
```
